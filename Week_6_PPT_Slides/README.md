## 🎨 Design Guidelines

### Color Scheme
- **Primary**: Blue (#4A90E2) to Purple (#7B68EE) gradient
- **Accent**: Gold untuk highlights
- **Status Colors**:
  - Green (✅) - Completed/Good
  - Orange (⚠️) - Warning/Medium priority
  - Yellow (🟡) - Low priority
  - Red (🔴) - Critical/High priority

### Fonts
- **Headings**: Poppins Bold, 36-48pt
- **Body**: Open Sans Regular, 18-24pt
- **Code**: Consolas/Courier, 14-16pt

### Layout Tips
- Gunakan white space yang cukup
- Maximum 5-7 bullet points per slide
- Tables maksimal 5 koloms untuk readability
- Icons/emoji untuk visual interest

## 📝 How to Use

### Option 1: Manual Copy-Paste
1. Buka file slide (contoh: `Slide_01_Cover.md`)
2. Copy konten utama
3. Paste ke PowerPoint slide baru
4. Apply design guidance yang tercantum
5. Gunakan speaker notes untuk preparation

### Option 2: Automated (dengan tool)
1. Gunakan Markdown to PPT converter (contoh: Marp, Slidev)
2. Atau import ke Google Slides dengan add-on
